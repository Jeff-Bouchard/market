About PrivateNess

NESS is a Skycoin fork. Its coin hours, NCH, grow with NESS holdings and pay for services. PrivateNess uses Emercoin for public names and identity records, with Bitcoin merged mining in Emercoin’s proof-of-work lineage.

PUBLIC RECORDS

Register a record.

Publish the information a domain, identity or service uses.
Review its content, owner and cost before confirming.

Example: dns:myname.emc. Replace myname with the name you want. We check whether it is already registered when you continue.

How to write a record name

Use the name required by your service. For an EmerDNS domain, use dns: followed by the domain, for example dns:myname.emc. Registering a name does not create or host a website.

For a domain name, you can keep these nameservers. This is a valid entry, ready to use. If your service supplies different settings, paste them here.

This information will be public, and copies can remain after the registration expires. Don’t include passwords or private recovery words.
